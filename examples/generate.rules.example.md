# 数据生成规则（模板）

> 本文件为规则模板。将其复制到项目根目录并重命名为 `generate.rules.md` 后编辑。
> Agent 会读取根目录的 `generate.rules.md`，本示例文件仅供参考。

## 全局配置

schema: public
默认每个表: 100 条

---

## department（部门表示例）

- 生成 10 条
- dept_name 从以下随机：研发部、市场部、财务部、人力资源部、运营部
- dept_code 格式：DEPT_{序号}

---

## employee（员工表示例）

- 生成 100 条
- status 随机：在职、离职
- email 格式：user_{序号}@example.com
- hire_date 范围：2020-01-01 到 2025-12-31

---

## 不生成的表

以下表不需要生成测试数据：

- sys_log
- audit_history
- temp_data

---

## 支持的写法速查

| 你想表达 | 示例 |
|----------|------|
| 全局默认条数 | `默认每个表: 100 条` |
| 某表条数 | `- 生成 100 条` |
| 枚举随机 | `- 字段名 从以下随机：值1、值2、值3` |
| 枚举随机（简写） | `- 字段名 随机：值1、值2、值3` |
| 固定格式 | `- 字段名 格式：前缀_{序号}_后缀` |
| 数值范围 | `- 字段名 范围：最小值 到 最大值` |
| 日期范围 | `- 字段名 范围：2020-01-01 到 2025-12-31` |
| 跳过表 | `## 不生成的表` 下列出表名 |

## 字段自动推断规则

未在规则文件中指定的字段，脚本会自动推断：

- id/PK → 自增或递增整数
- name/姓名/mc → 随机中文姓名或中文文本
- email → 随机邮箱
- phone/mobile/lxfs → 随机手机号
- address/dz/dwdz → 随机地址
- create_time/update_time → 近期随机日期
- 外键列 → 自动引用父表已插入行的 PK 值

## 使用方法

1. 复制本文件到项目根目录并重命名为 `generate.rules.md`
2. 根据你的实际数据库表结构编辑
3. 对 Agent 说：「按 generate.rules.md 生成数据」
